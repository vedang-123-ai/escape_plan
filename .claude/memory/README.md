# memory/

Durable, committed notes about the project: diagrams (`graphs/`), architectural-change history
(`lineage/`), and curated session/debug summaries worth re-reading (`logs/`). Create the
subfolders when the first artifact lands (S1.1's fixture graph renderings belong in `graphs/`).

Not the same thing as the machine-local session memory under `~/.claude/projects/` — that's
managed automatically and never committed. Day-to-day decision journaling stays in
`docs/decisions.md`; this folder is for larger artifacts that don't fit a table row.
