# S11.25: Residential size bounds for a HomeModel, enforced by the server and the editor alike · ~5h · Lane E (backend + one Swift file) · Prereqs: S11.14 (owner heads-up answered)

Context: HomeModel validation checks topology (CCW polygons, no self-intersection, references resolve, ids unique) but
never size. The navigation grid is built per room at 10 cm cells in pure Python, so route cost grows with floor area.
The audit measured `compute_route_plan(twostory, fire)` at 0.07 s at 1× scale, 1.15 s at 4× and 7.24 s at 10×, and
`/score` runs three plans per request. A single valid 1 km × 1 km room would run for hours and exhaust the free Render
instance, and the bearer token that guards it ships in every app (AUD-003). One request can take the demo backend down.
