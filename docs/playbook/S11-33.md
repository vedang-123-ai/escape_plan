# S11.33: Photo import sends a real JPEG the AI can read · ~2h · Lane D (iOS) · Prereqs: S11.26 (server allow-list and size limit)

Context: Import Plan's photo path passes the PhotosPicker asset's original bytes, HEIC for most iPhone camera photos
and often several MB, to `/build` labelled `image/png` (the client's default media type). The server forwarded that
label to Anthropic unchecked until S11.26. Anthropic accepts JPEG, PNG, GIF and WebP within a size limit, so a HEIC
photo, a type/label mismatch or an oversized image is rejected with a 400. The server turns that into 502 "The AI
service rejected the request", and the app shows "AI unavailable". The user concludes the AI is down. The PDF path
renders a real PNG and is fine. This is the accessibility fallback for phones without LiDAR.
