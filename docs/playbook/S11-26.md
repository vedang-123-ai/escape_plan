# S11.26: Request size limits and input caps on every endpoint · ~3h · Lane E (backend) · Prereqs: S11.14 (blocks S11.29, S11.33, S11.45)

Context: no endpoint limits the request body, so the server parses whatever arrives. The AI inputs are also unbounded:
`BuildRequest.description` and `image_b64` have no length limit; `image_media_type` is forwarded to Anthropic unchecked
(the iOS photo path labels HEIC/JPEG bytes as `image/png`, AUD-024); `ChatRequest.messages` has no count limit and
`ChatMessage.content` no length limit, so long threads grow until the model rejects them. Clients should be told
exactly what the server accepts, and the server should refuse early, before parsing or paying.
