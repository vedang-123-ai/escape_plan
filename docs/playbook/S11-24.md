# S11.24: Re-check a room end to end: a reducer-backed add, an honest error, a retry that works · ~3h · Lane D (iOS) · Prereqs: S11.19, S11.23 (HomeScreen serial order)

Context: "Re-check a room" is trace T6 in the audit: room picker → partial scan → `/convert` → `/diff_obstructions`
→ `DiffReviewSheet` → "Add to Home". Three defects sit on it. (1) "Add to Home" appends the object to a HomeModel
value inside the view and saves with `try?`: no EditorValidation, no undo, no room-containment check, and a failed save
is invisible while the score is recomputed as if it succeeded (AUD-017). (2) A failure on `/convert` or
`/diff_obstructions` is labelled as a score failure ("Getting your preparedness score needs a connection"), and the
banner's Retry re-runs the full-scan import. That either does nothing or, if an earlier full scan failed, imports that
old scan as a brand-new home (AUD-029). (3) Nothing confirms the object was saved (AUD-049).
