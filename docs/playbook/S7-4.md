S7.4 — The object-hazard engine · ~8h · Prereqs: S7.1, S7.2 (blocks S7.5, S7.7, S7.8)

Context: this is the arc's heart — the deterministic module that turns "there is furniture in
your model" into "the unsecured 1.9 m bookcase can reach your bed; strap it to studs." Five
rules, every one specified in docs/object-hazard-spec.md §4 with trigger geometry, thresholds,
severity, and citations. The demo's judge-proof line lives here: the AI never measures any of
this; a pure function does, and the AI can only quote it. The two live traps: the repo already
has a module named hazard.py (fire-origin simulation — the name is taken), and R4 is a widening
of the EXISTING obstruction engine, not a second one.

THE RESULT TYPE
ObjectHazard mirrors Obstruction's discipline: frozen dataclass; kind, room_id, room_name,
floor_id, object_id, target ("bed"/"sofa"/"egress"/None), measured value(s) with explicit
names (reach_m, gap_m, clearance_m — whatever the rule measured), threshold_m, severity,
citation (a source id that resolves in sources.json), and a detail property that writes the
deterministic sentence per the spec's patterns — number, threshold, citation-backed reason,
action. Every field the AI will later quote comes from here verbatim.
