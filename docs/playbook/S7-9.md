S7.9 — OPTIONAL: Vision photo-assist — capture and classify · ~5h · Prereqs: S7.6 (blocks S7.10; first to cut with S7.10)

Context: the hazard hunt asks the user questions; this optional session lets a photo answer
some of them first. Apple's on-device Vision framework can classify an image against its
built-in taxonomy — free, offline, no ML of ours. The scoping decision is loud and binding:
Vision SUGGESTS, the user CONFIRMS, and nothing enters the model without confirmation. A wrong
auto-detection in a safety app is worse than no detection. This session is also an honest
feasibility gate: nobody has verified that Vision's taxonomy can distinguish a space heater
from a radiator from a fan. If it cannot, the correct output of this session is a documented
negative result and a recommendation to cut S7.10 — that outcome is a SUCCESS, not a failure.
