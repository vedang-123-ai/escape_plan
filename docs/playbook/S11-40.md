# S11.40: Release builds keep app data out of the Files app, and raw scans are cleaned up · ~2.5h · Lane D (iOS) · Prereqs: S11.24 (re-check flow settled)

Context: `UIFileSharingEnabled` and `LSSupportsOpeningDocumentsInPlace` are YES in both Debug and Release. They were
added so raw scans could be pulled off the phone as converter fixtures. So in a shipped build, anyone with the unlocked
phone, or Finder over USB, can browse, copy, edit or delete every home (floor plans, household names, optional
address), the sync sidecar (ownership claims), chats, the drill log, the route cache and every raw scan. Deleting a home
file there bypasses the sync tombstone, so sync re-downloads it. Raw RoomPlan exports under `Documents/Scans/` are
never deleted, including every partial re-check. The S11.7 disclosure promises care about what leaves the device; the
Files app exposes more than the app itself shows.
