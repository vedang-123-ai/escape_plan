S7.1 — Schema 2.1: objects gain height, mounting, and hazard categories · ~5h · Prereqs: none (blocks S7.3, S7.4, S7.6)

Context: today a `FloorObject` is a floor-standing extruded box with a render-only category —
"a heavy object mounted high over the bed" is literally unrepresentable, and a stove is just an
`appliance`. Every rule in `docs/object-hazard-spec.md` §4 needs the three small additions this
session makes. It is the arc's only schema bump; everything downstream reads what you add here.
The delicacy is the usual one: the schema is the project's one law, and a change is incomplete
until JSON Schema, pydantic, and Swift agree — plus one extra tripwire unique to objects: the
Swift renderer's `FurnitureFixture` switch is exhaustive over `ObjectCategory`, so a new enum
case without a renderer arm stops the app compiling.

WHAT TO ADD (and nothing else)
1. FloorObject.elevation_m — number >= 0, default 0. Height of the object's BASE above the
   floor. 0 keeps today's implicit meaning; a wall-mounted TV gets its real base height.
2. FloorObject.mounted — boolean, default false. Attached to wall/ceiling rather than
   resting. Distinct from `secured` (anti-topple strapping); do not merge them.
3. ObjectCategory gains: bookcase, tv, water_heater, heat_source. The existing seven values
   are untouched. heat_source covers fixed stoves/ovens/fireplaces AND portable heaters —
   the spec deliberately uses one category.
4. schema_version: "2.1". While here, resolve the logged breadth disagreement (see
   docs/tracker/TODO.md, "schema_version breadth disagrees three ways"): make the JSON
   Schema accept the versions the migrators accept, make pydantic's Literal current-only,
   and document the ruling in decisions.md. Migrator: 2.0 → 2.1 is a version-stamp bump
   (all additions are defaulted); keep the numeric version compare that replaced the
   lexical one.
5. Fixture seeding, both sides of every rule in the spec: give jagged.json an unsecured
   tall bookcase whose topple band reaches a bed AND a secured one that must stay silent;
   give twostory.json a heat_source with a sofa inside 0.9 m AND a water_heater with
   secured=false; give one fixture a mounted tv with elevation_m over a bed. Do NOT
   change object placements existing tests depend on — add, don't move, and run the full
   backend suite after each fixture edit to prove it.
