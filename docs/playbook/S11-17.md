review" (spec §4: "Draft-only, mandatory editor review, never presented as scan parity"). Since `87c0610` deleted
`BetaScreen`, the build completion handler makes the draft the active home, and `ReadinessStore` immediately calls
`/score`. That computes three route plans and a readiness band for a floor plan an LLM guessed from a sentence or a
photo. House, meanwhile, refuses to draw routes for the same model until the draft is reviewed. The user sees a score
the rest of the app will not stand behind.
