# S11.11: Integration gate and golden-path polish · ~6h · All lanes, one person at a time · Prereqs: S11.1 to S11.10 (blocks S11.12 truth pass, S11.13)

Context: ten sessions on ten branches will have merged. This session proves they coexist, runs the whole gate
on the merged `main`, walks the golden path as a judge would, and fixes what would read badly on camera.
Announce in the group chat when you start: nobody else merges to `main` while this runs.

```
Read CLAUDE.md, docs/playbook/README.md, docs/tracker/BLOCKERS.md (all of it, it is the polish backlog) and the
notes from S11.1 to S11.10.

BRANCH (read this first)
  git fetch origin && git switch -c s11-11-integration origin/main
  Work ONLY on this branch. Never commit to main. Confirm `git branch --show-current` before every commit.
  Touch only what a verified defect requires; list each file in the note.
  Before finishing: git fetch origin && git merge origin/main, re-run ACCEPTANCE, then
  git switch main && git pull && git merge --no-ff s11-11-integration && git push.

OWNED FILES
  any file a proven defect touches (serial session). Prefer the smallest possible fix.

MISSION
1. Run the lane-integrator agent over the merged main; resolve semantic (not textual) conflicts it finds.
2. Run /verify (the whole gate) and, on the simulator machine, the full xcodebuild suite with counts from
   xcresulttool. Zero unexplained reds.
3. Run python3 scripts/demo-preflight.py. It needs escape_plan/BackendConfig.local.json (gitignored, owner
   creates it) and the Anthropic account topped up for the AI checks; record which checks could not run and why.
4. Walk the golden path on the device as a judge: onboarding, build or open a home, routes, switch profiles,
   drill, score, share snapshot. Fix every dead tap, unexplained wait and confusing label that would read badly on
   camera. File the rest in BLOCKERS.
5. Re-read the pitch claims list in the S11.12 draft against what now exists, and flag anything unshipped.

RULES
- No feature work. If something is missing, it is either cut from the pitch or logged, not built here.
- Do not weaken a test to get green.

DELIBERATELY NOT IN THIS SESSION
- New features, refactors, redesigns.

ACCEPTANCE
- /verify green on the merged main; full simulator run green with real counts; demo-preflight exit 0 (or each
  exception recorded); golden path walked with a written list of what was fixed and what remains.
- Run session-auditor on S11.1 to S11.10 against their acceptance criteria and doc-auditor across docs/.

CLOSE OUT
Rewrite the BLOCKERS header with verified counts and date. Write the note. Set the "shippable" verdict plainly:
ready to film, or the specific list that is not.
```
