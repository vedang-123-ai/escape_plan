# S11.34: Checklist recurrence works through /score (server side) · ~3h · Lane E (backend) · Prereqs: S11.27 (main.py serial) (blocks S11.35; must be DEPLOYED before S11.35 ships)

Context: the backend implements time-based staleness for recurring checklist items, but the only production caller
cannot use it. `ScoreRequest.checklist_state` is `dict[str, bool]`, so a completion timestamp is rejected, and `/score`
calls `compute_score` without `now`. With no clock, any truthy value counts as "done" forever. So finishing one drill
ticks "Practice the plan (twice a year)" permanently, "Rescan your home" likewise, and "Test every smoke alarm this
month" has no recurrence at all. Home can say "Last practiced: 8 months ago" while Tasks shows the drill done.
Practising twice a year is the core habit the app exists to build. No backend test exercises recurrence at all.
