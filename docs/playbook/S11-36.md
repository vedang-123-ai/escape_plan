# S11.36: The offline route cache never serves another peril's or another person's route · ~2.5h · Lane D (iOS) · Prereqs: S11.20 (DrillScreen serial order)

Context: the last-good route plan is cached once per home, keyed only by `home_id`. Whichever `/routes` call last
succeeded wins, whatever the peril (fire, tornado, earthquake) or profile (constraints such as no stairs). Offline,
starting a tornado drill can load the cached fire plan; the drill then follows `plan.peril` ("fire"), so the user
practises the wrong peril while the picker says tornado. A wheelchair user's drill can load another person's route
through stairs. After an edit, a cached plan can reference rooms and openings that no longer exist. The banner says
"cached", but not whose route or which peril.
