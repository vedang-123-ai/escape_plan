# S11.18: One HomeDocumentStore for the whole app · ~1.5h · Lane D (iOS) · Prereqs: S11.14 (blocks S11.19, S11.20, S11.21)

Context: `escape_planApp` builds one launch store (`HomeDocumentStore.launchStore()`) with a temp-directory fallback and
a "Storage unavailable" banner. Six screens ignore it and build their own `HomeDocumentStore()`, so in the fallback
state they write to the real Documents path while the library reads the temp one. `HouseScreen` builds one on every
struct init. This is already on BLOCKERS ("Found while doing this"). It is also the foundation for S11.19: House can
only learn that someone else wrote its home if every writer goes through one store instance.
