# S11.16: The privacy copy says what actually leaves the phone · ~2.5h · Lane D (iOS) · Prereqs: S11.14; land after S11.8 if it touches SignedOutPathUITests

Context: the sign-in gate and Settings say that signed-out use "uploads nothing about your home" and that no photo "is
ever sent". In fact every `/routes`, `/score`, `/evacuate` and `/chat` request sends the whole HomeModel: room names,
household members' names, their vulnerability tags, where each sleeps, and the optional street address. Import Plan
sends the chosen photo or PDF page to the server, which forwards it to Anthropic. The server stores none of these
requests, so "stores nothing" would be true where "uploads nothing" is false. The tests pin the false phrase.
`AccountPrivacy.swift` says a judge can verify every line against the code, and App Review checks privacy labels
against behaviour. The same disclosure also never says that checklist progress, the drill log and chats stay on the
device (AUD-018). One sentence is the cheapest honest fix for that.
