# S11.29: AI calls time out and stop when the phone has given up · ~3h · Lane E (backend) · Prereqs: S11.26, S11.27 (blocks S11.37, S11.39, S11.44, S11.49)

Context: every AI module builds `anthropic.Anthropic(api_key=...)` per request with SDK defaults: a 600 s timeout and 2
retries. The endpoints are synchronous, so each holds a threadpool thread and one of the 4 AI slots until it returns.
Nothing stops a long agent or builder loop when the phone gives up. A `/build` that passes the app's 180 s timeout keeps
iterating (up to 40 model calls) with its result discarded, and the user's Retry starts a second loop. The builder puts
the image in the first user turn, so it is re-sent on every iteration as history grows.
