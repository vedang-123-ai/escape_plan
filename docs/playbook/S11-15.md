# S11.15: The drill shows the engine's findings verbatim, never its own tornado advice · ~1.5h · Lane D (iOS) · Prereqs: S11.14 (before S11.12's truth pass)

Context: when the engine cannot reach an interior room in a tornado drill, `DrillScreen` appends its own sentence to
the engine's finding: "Leave immediately and seek shelter in a nearby sturdy building. [cite: redcross-tornado]". The
engine limits that advice to mobile and manufactured homes. For a site-built house, NWS and Red Cross guidance is the
opposite: lowest floor, interior room. So the client is writing safety guidance, the one thing this project promises
never happens, and it shows a raw cite tag. A comment two lines below the code already states the rule it breaks
("the app never writes its own safety judgments").
