## Decisions / surprises

(Both promoted to docs/decisions.md.)

- **500 vs 502:** `api_chat.py` doesn't catch the base `GroundingError`, so a missing key
  surfaces as a generic 500; 502 is specifically citation-validation failure. The client
  treats all 5xx as one graceful "assistant unavailable" state, so it's robust either way —
  but P1 may want to mirror `/explain`'s handling in `api_chat.py`.
- **Wire/persisted type split:** server messages are `extra="forbid"` `{role, content}` only,
  so the persisted `AssistantMessage` (id, citations) projects down via `.wireMessage` —
  a leaked extra key would 422 every call. Locked by `ChatRequestEncodingTests`.
- `route_plan`/`profiles` not sent in v1 (optional server-side). Easy follow-up once the Plan
  tab's RoutePlan is shareable state.
- `APIClient.session` is private, so the extension uses `URLSession.shared` directly (the
  client's default anyway); noted in-file.
