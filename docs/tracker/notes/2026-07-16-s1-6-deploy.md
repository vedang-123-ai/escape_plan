# S1.6 — Backend deploy (human step)

- **Who:** P1 driving P3 (Claude Code), P1 doing the browser/account parts
- **Date(s):** 2026-07-16
- **Status when I stopped:** deployed and verified via curl; phone-on-cellular timing check deferred by team decision

## What happened

- P1 created a Render account and used the **Blueprints** flow (not "New → Blueprint" —
  Render's current UI puts it elsewhere; P1 found it via the New menu after a short back-and-forth)
  to deploy the committed `render.yaml`. Blueprint prompted for blueprint name, path, branch,
  and the `ANTHROPIC_API_KEY` value up front (not just in the post-deploy Environment tab as
  `backend/README.md` implied).
- Confirmed `ANTHROPIC_API_KEY` is **not** required to boot (`app/config.py` only requires
  `BACKEND_BEARER_TOKEN`, fails closed without it; the Anthropic key is read as optional and
  only touched inside `/explain` at request time). P1 left the field **blank** on the Blueprint
  form — it was accepted, no placeholder needed.
- Service is live at `https://escape-plan-backend.onrender.com`. Verified from a dev machine via curl:
  - `GET /health` → 200 OK, `{"status":"ok","version":"1.0"}`, ~0.39s (warm)
  - `POST /routes` on `twostory.json` → 200 OK, valid `RoutePlan` (primary out `d_front`,
    secondary via stairs), ~0.27s (warm)
  - Both well under the 2s acceptance bar.
- `BACKEND_BEARER_TOKEN` (Render's auto-generated value) was shared in chat by P1 for
  verification purposes only — it is **not** written to any tracked file; it belongs in the
  team password note (P1 confirmed this is handled).
- The formal **phone-on-cellular <2s check was not run**: P1's test phone has no REST client
  installed. Considered alternatives (hotspot-tether the dev machine through the phone,
  build an iOS Shortcuts request) but the team decided to **defer** rather than spend time on
  it today, since nothing else on the board is currently blocked on that number (S0.3 hadn't
  landed yet at the time of this decision, so `APIClient.swift` wasn't wired to anything real).
  It will get exercised naturally once P2 points the app at the live URL.

## Decisions / surprises

- Render's Blueprint UI asks for `sync: false` env var values (like `ANTHROPIC_API_KEY`) at
  *creation* time, not only later in the dashboard's Environment tab as `backend/README.md`
  § Deploy currently describes — worth a doc tweak if this trips up the next person following
  those steps literally, but not urgent since it worked fine either way (blank was accepted).
- Promoted to `docs/decisions.md` (2026-07-16, S1.6 (deploy)): the unset-key choice and the
  deferred-cellular-check decision, with reasoning.
