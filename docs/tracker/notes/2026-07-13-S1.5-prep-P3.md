## What happened

- Documented the **assumed** RoomPlan export format in `backend/app/convert/README.md`
  (CapturedRoom/CapturedStructure via Swift JSONEncoder: column-major simd 4x4 transforms,
  `{"high": {}}` confidence enums, per-room walls/doors/windows/openings arrays, sections
  for room labels). This doc is the diff target when S1.4's real exports arrive.
- Built `backend/app/convert/` (pure functions, pydantic v2, no I/O):
  - `roomplan.py` — lenient input models (`extra="ignore"`, accepts string or object
    confidence, flat or nested transforms).
  - `geometry.py` — walls → polygon pipeline: greedy chain → midpoint gap-weld →
    near-collinear merge (8°) → rectangularize to dominant axis (12°) → CCW/simple
    normalize, with bbox fallback at quality 0.3. Opening → nearest-parallel-edge
    (edge_index, t0, t1) placement. Tolerances are module constants for the
    calibration pass.
  - `converter.py` — `convert_scan(export, home_name=, timestamp=)` → validated
    `HomeModel`. Shared doors paired by identifier, then geometric coincidence;
    unpaired → EXTERIOR; unresolvable placements demoted to conf ≤0.25, never dropped;
    uuid5-deterministic ids → idempotent output.
- 3 synthetic fixtures in `schema/fixtures/scans/` generated by
  `backend/scripts/gen_scan_fixtures.py` (clean bungalow / messy / geometric shared door).
- `backend/tests/test_convert.py`: 18 tests — ground-truth footprints and opening spans,
  JSON Schema + pydantic validity, idempotency, low-confidence flagging, lenient parsing.
