- Built `backend/app/ai/chat/` (new module):
  - `summary.py` — pure functions, no I/O: `summarize_home`, `summarize_route_plan`,
    `summarize_profiles` turn a `HomeModel`/`RoutePlan`/`list[Profile]` into compact text

    corpus block (reused via `grounded.corpus_text()`/`valid_source_ids()`, not
    re-embedded) + a cached house/plan/profile context block. In-prompt safety behaviors:
    emergencies → "get out, call 911" first line; out-of-corpus topics → honest deferral.
    Citation contract: inline `[cite: source-id]` tags are validated against
    `sources.json`; fabricated ids trigger the same reject/retry loop as `/explain`
    (`ChatGroundingError` → HTTP 502 at the endpoint); zero citations is fine (chit-chat
    and 911 deferrals need none).
- `backend/app/api_chat.py` — new router file, `POST /chat` behind the same bearer-token
  dependency as every other non-health endpoint. Wired into `app/main.py` with two lines
  (an import + `app.include_router(chat_router)`) — no other existing file touched.
- Tests: `backend/tests/test_chat.py` (21 mocked/structural tests: summaries, system-prompt
