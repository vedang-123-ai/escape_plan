# HomeModel v2.1 — team summary (S0.2 handoff; v1.1 2026-07-23; v2.0 readiness pivot; v2.1 object hazards, S7.1)

1. One JSON document per home: `schema_version ("2.1"), home_id, name, floors[], stairs[], profiles[], meta, household?`. Contract lives at `schema/homemodel.schema.json`; changes require a `schema_version` bump plus a clean `schema-contract-guardian` run — **agent review, no human sign-off and no PR gate.** The `schema_version` enum deliberately lists every version the migrators accept (`1.0`, `1.1`, `2.0`, `2.1`) because it validates documents on disk; pydantic is narrower (`Literal["2.1"]`) because it validates the post-migration in-memory model.
2. A floor = `id, level (unique int), name, height_m, rooms[], openings[], objects[]`; all coordinates are meters in a floor-local 2D frame.
2b. **v1.1, extended in v2.1** — an object = `id, category, center, size_m [w,d], height_m, rotation_deg (default 0), secured (default false)`, plus **v2.1**: `elevation_m` (number ≥ 0, default 0 — the height of the object's BASE above the floor, so the prism spans `elevation_m .. elevation_m + height_m`) and `mounted` (bool, default false — attached to a wall/ceiling rather than resting; deliberately NOT the same thing as `secured`, which is anti-topple strapping). Categories are `bed|sofa|table|wardrobe|appliance|storage|other` plus **v2.1**'s `bookcase|tv|water_heater|heat_source` (one `heat_source` covers fixed stoves/ovens/fireplaces AND portable heaters — the clearance rule is the same for all of them). Both v2.1 fields are defaulted, so every 2.0 document is a valid 2.1 document minus the stamp. An object is a rotated box primitive, rendered as a prism and treated as an obstacle by within-room routing. No room_id on purpose — containment is derived geometrically. `objects` defaults to `[]`; every migration to date (1.0 → 1.1 → 2.0 → 2.1) is a version re-stamp, because every addition has been optional and defaulted (SchemaMigrator, both sides).
3. A room = `id, name, type (bedroom|living|kitchen|hall|bath|garage|other), polygon` — CCW, non-self-intersecting, first vertex not repeated; 3D is extruded from `height_m`.
4. Edge convention: edge *i* runs vertex *i* → vertex *(i+1) mod n*. Openings sit on walls parametrically: `wall_segment {room_id, edge_index, t0, t1}` — drag a wall and its doors ride along.
5. An opening = door|window with `room_ids` (always exactly 2): two rooms = interior adjacency; room + `EXTERIOR` (reserved pseudo-room) = an exit. `width_m/height_m/sill_height_m` are authoritative for egress checks.
6. `egress {viable, reasons[]}` is computed-only (S1.1 annotator, IRC thresholds from the corpus) — never hand-authored, never AI-authored.
7. Stairs connect `from {floor_id, room_id}` → `to` on a *different* floor (JSON key is `from`; pydantic field is `from_`, Swift should use CodingKeys).
8. Provenance: everything carries `source: scan|manual|ai_plan` (v1.1 adds `ai_plan` = drafted by the LLM house builder); scan and ai_plan items MUST carry `confidence`, and ai_plan homes force editor review before routes are computed (low values get "needs review" treatment in the editor, never silently dropped).
9. Ids are globally unique across ALL entity kinds (floors, rooms, openings, stairs, profiles); `additionalProperties: false` everywhere — unknown fields fail validation.
10. Validate with `cd backend && python3 -m app.validate ../schema/fixtures/*.json` (runs JSON Schema + pydantic). Fixtures: `bungalow` (clean), `apartment` (planted: single exit, all windows non-viable), `twostory` (planted: kids' window too small; profiles Maya/Grandpa), `bungalow-blocked` (v1.1 planted: wardrobe fully blocking the bedroom doorway + sofa mid-living-room — B3 obstacle-routing tests assert the re-plan) + `jagged` (multi-floor, planted with the **v2.1 object-hazard bed**: an unsecured bookcase whose topple band reaches a bed, a secured twin placed to reach it from the other side, and a `mounted` TV at `elevation_m` 1.35 over the bed) + `fixtures/invalid/` for failure cases. `twostory` also carries the clearance pair — a `heat_source` 0.425 m from a sofa and another 4 m away. **Every planted hazard has a planted non-hazard**: S7.4's rules must fire on one and stay silent on the other, and `backend/tests/test_object_hazard_fixtures.py` keeps the controls geometrically capable of firing so they cannot pass for the wrong reason.
