# schema/

Home of the HomeModel contract:

- `homemodel.schema.json` — JSON Schema (draft 2020-12), finalized in S0.2. Schema is law; changes after S0.2 require a version bump + team sign-off.
- `fixtures/` — synthetic test homes built in S0.2: `bungalow.json`, `apartment.json`, `twostory.json`, plus `scans/` for raw RoomPlan exports (S1.4).

Schema sketch and invariants: `archive/playbook-v1:docs/playbook/02-architecture.md` §2.2 (and `docs/schema-summary.md`).
